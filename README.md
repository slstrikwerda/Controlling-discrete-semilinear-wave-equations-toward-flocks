# Controlling-discrete-semilinear-wave-equations-toward-flocks
[![DOI](https://zenodo.org/badge/1427587060.svg)](https://doi.org/10.5281/zenodo.23899173)

This code accompanies the paper called Controlling discrete semi linear wave equations toward flocks. 
The script requires Python 3 with the packages NumPy, SciPy, Maplotlib, and pandas. The script was tested with Python 3.13.3, NumPy 2.5.4, SciPy 1.18.1, Matplotlib 3.11.2, and pandas 3.1.0. 
The script performs the numerical construction for the examples described in "Controlling discrete semi linear wave equations toward flocks". The main example is when M=1. A threshold study is also computed. The code will generate the figures used in the paper.
The script also contains numerical checks of the construction. The numerical checks are intended as floating-point verification of the explicit construction and are not substitutes for the analytical arguments in the manuscript.
ChatGPT (OpenAI) was used to assist with drafting and debugging the Python implementation and preparing numerical illustrations. Sarah Strikwerda, Hung Vihn Tran, and Mihn-Bihn Tran reviewed and corrected the code. They take full responsibility for the content.
